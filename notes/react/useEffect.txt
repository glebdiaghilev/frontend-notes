в react компонентах есть разные моменты жизненного цикла:
старый react код:
class Example extends React.Component {
    /* компонент впервые появился на экране */
    componentDidMount() {
        console.log('component is mounted')
    }

    /* компонент обновился из-за изменения данных */
    componentDidUpdate() {
        console.log('component is updated')
    }

    /* компонент удалился */
    componentWillUnmount() {
        console.log('component is deleted')
    }

    render() {
        return <div>hello, world!</div>
    }
}

в старом react, когда компоненты создавались через
js классы, для этого были специальные методы.

в современных функциональных компонентах эти методы
заменяются одним специальным инструментом, хуком useEffect.
новый react код:
import { useEffect } from "react";

const Example = () => {
    useEffect(() => {
        // your side effect
    }, [/* dependencies */])

    return <div>hello, world!</div>
}

он позволяет выполнить код после того, как компонент отрисовался
или обновился, а так же выполнить уборку перед удалением.
useEffect используют для любых побочных эффектов кода,
не связанного напрямую с отрисовкой интерфейса, например,
загрузка или сохранение данных через сервер, работа с 
localStorage, подписки и таймеры.

используется useEffect в теле функции, отвечающей за компонент.
первый аргумент - это функция, которая выполняет нужное действие.
второй аргумент - это массив зависимостей.
второй аргумент:
1. если массив зависимостей пустой, то useEffect выполнится
только один раз при первом рендере;
2. если в массиве зависимостей есть данные, то useEffect 
будет срабатывать каждый раз, когда зависимости меняются.

useEffect умеет очищать за собой. если в теле callback,
который мы указываем первым аргументом, вернуть функцию,
она выполнится при удалении компонента.
пример:
import { useEffect } from "react";

const Example = () => {
    useEffect(() => {
        // your side effect
        return () => {
            // will be executed when the component is removed
        }
    }, [/* dependencies */])

    return <div>hello, world!</div>
}

это полезно для очистки таймеров или отписки от событий.
