props - это способ передавать данные в компонент из-вне. когда мы 
используем компонент, как тег, мы можем передавать туда какие-то параметры.

например: <TodoItem /> - в него можно передать какие-либо параметры, 
как атрибуты: <TodoItem title="buy a milk" isDone={false}/>.

эти параметры называются props (от слова properties).
внутри компонента они приходят, как объект.

props передаются только сверху вниз от родителя к ребенку. компонент не должен
изменять переданный props, он их только читает. эти правила делают интерфейс
предсказуемым и приятным.

пример:
создаем компонент:
const Greeting = (props) => {
    return (
        <h1>hello, {props.name}!</h1>
    )
}

export default Greeting

используем компонент:
import Todo from "./components/Todo"

const App = () => {
  return (
    <>
      <Todo />
      вот тут передаем данные для props:
      <Greeting name="gleb" />
      <Greeting name="brainrot" />
      <Greeting name="alex" />
    </>
  )
}

export default App

компоненты выводят разные данные в зависимости от того, что в них передали.

когда prop передается по большой цепочке, например:
todo -> todoList -> todoItem - это называется
prop drilling, и в больших проектах подобные цепочки
становятся неконтролируемыми.

children - это все, что находится между открывающим и закрывающим тегом компонента.
