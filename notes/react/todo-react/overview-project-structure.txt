обзор на структуру изначального стартового проекта: 

в данном проекте мы используем сборщик vite версии 7.0.3 и работает
с javascript в react. 

после генерации шаблона в проекте появляется множество файлов и папок.

package.json - главный файл конфигурации проекта. хранит список зависимостей:
react, react dom, vite и прочее. содержит скрипты: dev, build и т.д.
и базовую информацию о проекте. именно его читает npm install, чтобы понять,
что устанавливать в node.modules.

package-lock.json - технический файл, который фиксирует точные версии всех
установленных пакетов. он нужен для того чтобы у всех разработчиков была 
одинаковая среда с идентичными версиями библиотек.

node_modules - папка со всеми установленными зависимостями, она создается
автоматически при установке пакетов и обычно не "коммитится" в репозитории.

.gitignore - файл, который говорит git, какие файлы и папки не стоит отслеживать
для изменений последующих коммитов и пуша в репозитории

vite.config.js - файл конфигурации сборщика vite, который используется здесь
под капотом, при необходимости туда можно добавить настройки путей.

eslint.config.js - конфигурация линтера eslint. линтер нужен для анализа
кода на ошибки и несоответствия правилам.

README.md - файл с описанием проекта.

public - папка для статических файлов в которой должны быть доступны напрямую 
без сборки.

здесь есть стартовая страница приложения index.html. в отличие от webpack и
create react app vite работает с обычным html файлом напрямую. здесь подключается
корневой js файл.

в src есть файл main.jsx - точка входа в js код. именно здесь происходит
запуск react приложения. createRoot создает корень react приложения.
находим в Index.html элемент с id="root" и туда вставляем все приложение.
внутри strictMode рендерится корневой компонент app.

strictMode - специальная обертка от react, которая помогает находить
потенциальные проблемы в коде во время разработки. на функциональность
приложения эта обертка не влияет, но она может дергать компоненты дважды.

app.jsx - корневой компонент приложения. весь контент страницы расположен
здесь.

index.css - файл, который содержит базовые стили приложения, которые подключаются
в main.jsx.

app.css - файл, который содержит стили компонента app.

в папке src есть папка assets - она складирует ассеты: картинки, шрифты, иконки.
