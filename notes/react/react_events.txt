в обычном js мы работаем с dom элементами напрямую и пишем:
document
  .querySelector('.todo__delete-all-button')
  .addEventListener('click', () => console.log('click!'))

в react другой подход. мы указываем обработчики сразу в jsx
и не ищем элементы вручную, например:
<button 
  className="todo__delete-all-button" 
  type="button"
  здесь мы вешаем обработчик
  onClick={() => console.log('click!')}
>

отличия от событий в react от js:
1. имена событий пишутся в camelCase;

2. в значении props мы передаем функцию, а не строку.
для наглядности:
1) пишем функцию:
const handleClick = () => {
  console.log('click!')
}
2) передаем функцию:
onClick={handleClick}

3. объект события в react - это не стандартное событие
js, а synthetic event.
react дополнительно оборачивает браузерное событие в свой 
объект synthetic event.
делается это для того чтобы унифицировать отличие event 
в разных браузерах. работать с этим event можно точно так же,
как и с обычным event.

4. в react не нужно искать элементы в dom дереве. можно навешивать
обработчики прямо на компонент или на конкретный элемент.
